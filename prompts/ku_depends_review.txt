# 任务
判断给出的候选 depends_on 边是否成立。语义约定：
「A depends_on B」表示「学习 A 之前应先掌握 B」，即 B 是 A 的**先修/语义前提**（B 的核心内容被 A 的定义、主要结论直接使用或默认预设）。

# 接受标准（满足其一即可接受）
1. B 的中心目标确实是 A 的语义前提：A 的定义或主要结论**直接使用** B 的核心内容（例如：函数的连续性以极限概念为前提，曲线在某点连续的定义直接引用 lim f(x) = f(x0)）。
2. 候选证据中的 `defined_in_terms_of` / `derived_from` / `uses` 边构成明确的语义前置链（例如：间断点分类用左/右极限定义 → 单侧极限以函数极限定义 → 间断点分类依赖函数极限定义）。
3. 链候选（A → 中间单元 → B）：链的每一跳都是真实的定义/推导关系，且从教材数学语义看 B 确实是 A 的合理先修。

# 拒绝标准（任一条即可拒绝）
1. 仅「内容相关/主题相近」：A 与 B 讨论同一主题或共享概念，但无先修关系（例如：极限的保号性 与 极限定义 只是同属"函数极限"主题，保号性**使用**极限概念，属于依赖——请区分：被**使用为工具**才是前提；只是**同主题列举**不是）。
2. B 对 A 只是「被讨论的对象」，不是前提。例如「初等函数在其定义区间内的连续性」**讨论**初等函数，讨论对象不是先修前提。
3. 通用公共基础锚：即使候选里剔除了多数，仍需警惕「涉及函数 / 涉及映射」这类对任何单元都天然成立的依赖，不成边。
4. 证据仅剩 `involves(center)` 且其含义是 A 的中心节点"涉及"B 的中心概念，而教材语义上 B 不是 A 的工具/前提。
5. 教材章节顺序相邻本身不构成依赖（例如后面的节**提到**前面的概念不算）。
6. 证据是 `special_case_of`（从属关系 ≠ 先修依赖）。

# 强度标注
- `strong`：定义直接引用 / 推导直接依赖，教科书语义上没有争议（如 连续性→极限定义、间断点→左/右极限）。
- `weak`：成立但有边界可商榷，或仅凭中心概念的涉及关系支持（如 反函数连续性的中间结论用到单调性概念）。

只输出 JSON（不要输出其他内容）：

对每一个给出的 index 都必须给出结论，reason 用一句中文说明依据（引用具体证据或数学语义）。
