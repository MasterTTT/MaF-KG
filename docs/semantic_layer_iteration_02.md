# 第一层语义图迭代记录 02

## 实验目标

本轮将第一层语义图升级为 `maf-kg.semantic.v1.3`，重点验证四项修改：

- 将 Claim 分为 `property`、`criterion`、`identity`、`result`；
- Concept description 只保留定义性内容，独立性质进入 Claim；
- evidence 增加教材标题路径、教学块和话语角色；
- 改进结构感知分块，避免定义或公式说明在边界处被截断。

抽取仍采用单 Extractor、顺序 Top-K memory 和全局图增量合并，不增加后处理 Agent，也不使用规则抽取或语义 fallback。

## 实验设置

- 模型：`deepseek-v4-pro`
- thinking：`enabled`
- reasoning effort：`medium`
- max tokens：`24000`
- 第一节：12 个结构感知 chunk，跳过习题
- 第二节：5 个结构感知 chunk，跳过习题并关闭本地断点读取
- 实验产物只保存在本地 `KG/` 与 `node_cache/`，不纳入 Git

## 第一节结果

对照文件为本地 v1.2 与 v1.3 结果。

| 指标 | v1.2 | v1.3 |
| --- | ---: | ---: |
| 节点 | 75 | 82 |
| Claim / Concept / Method | 28 / 47 / 0 | 32 / 50 / 0 |
| 关系 | 109 | 129 |
| MathExpression | 43 | 47 |
| 孤立节点 | 3 | 0 |
| 连通分量 | 5 | 2 |
| 悬空端点 / 自环 | 0 / 0 | 0 / 0 |

v1.3 的 32 个 Claim 均获得分类：18 个 `property`、4 个 `criterion`、8 个 `identity`、2 个 `result`。第一节恢复了 v1.2 漏掉的复合映射非交换性、函数奇偶分解定理、单调增加和单调减少的完整定义，以及周期相关结论。单调性定义所在的 284--365 行被保留在同一 chunk，未再发生跨块截断。

第一节仍存在三项问题：

1. 函数和、差、积、商被拆为四个 Concept，粒度可能偏细；
2. 正文中的“ 双曲函数”总类 Concept 被漏掉；
3. 少量 Claim description 混入了证明性解释，偶函数和奇函数的节点证据跨度仍偏宽。

综合语义覆盖、Claim 边界和图结构，第一节相对 v1.2 有明确提升，但并非已经达到最终 schema 质量。

## 第二节泛化结果

第二节 v1.3 得到 16 个节点、22 条关系和 4 个 MathExpression，其中 9 个 Claim、6 个 Concept、1 个 Method。Claim 包含 5 个 `result` 和 4 个 `criterion`。结构上不存在悬空端点、自环或身份冲突。

抽取正确覆盖了极限唯一性、收敛数列有界性、保号性、保序推论、子数列定理和由两个不同子列极限判定发散的准则；`derived_from` 也正确连接了子列发散准则与子数列定理。

泛化结果同时暴露出明显退化：

1. `ε 邻域`、全称量词、存在量词和数列收敛等教材概念被漏掉；
2. “接近程度可用差的绝对值度量”和“绝对值不等式等价性”被过度提升为孤立 Criterion；
3. 与此前 v1.1 Pro 结果相比，节点由 19 降至 16、关系由 25 降至 22、MathExpression 由 11 降至 4；
4. 第二节出现 2 个孤立节点，说明“Claim 应连接主要 Concept”的提示没有稳定泛化。

因此，本轮不能得出 v1.3 已普遍优于旧版的结论。更准确的判断是：Claim 分类和第一节的性质覆盖得到改善，但节点选择策略在极限章节上偏保守，同时 Criterion 边界偏宽。

## 协议故障

第一次运行在第 5 个 chunk 连续失败。模型对 `reuse` 动作输出了空字符串 `type: ""`，严格 Pydantic Schema 正确拒绝了该响应。原因是提示词文字要求 reuse 不填写 type，但 JSON 示例仍给出了 `type: "Concept"`，形成自相矛盾的输出契约。

修复方式是让 reuse 示例彻底省略 `type`、`name` 和 `claim_kind`，并明确禁止为空枚举输出空字符串。该修改没有对错误响应进行静默转换，也没有增加兼容性 fallback。修复后两节共 16 次 API 请求均成功。

## 下一轮假设

下一轮不应继续增加 Agent。优先验证以下两项：

1. 收紧 Criterion：仅保留明确的必要、充分、充要、判定、存在唯一性或适用条件，普通等价改写和度量说明不得独立成 Claim；
2. 为“教材明确定义的核心概念”增加一次 chunk 内覆盖自检，重点解决第二节 Concept 召回不足，但不通过固定词表或规则回填节点。

在完成跨章节人工标注集前，不把节点数量或连通率单独作为质量提升证据。
