# 第一层语义图迭代记录 05

## 实验问题

本轮检验一个单变量假设：在 chunk 文本与边界完全不变时，显式告诉模型每个教材 block 的 `discourse_role` 和行范围，是否能改善第一层语义节点与关系抽取。

对照版本为 v1.5.2/v1.5.3。实验版本 v1.5.5 只新增紧凑的 `teaching_blocks` 描述：

```json
{
  "teaching_block_id": "teaching_0014_112_112_528664cb",
  "discourse_role": "paragraph",
  "start_line": 112,
  "end_line": 112
}
```

角色仅作为导航提示，带行号的 `chunk.text` 仍是唯一事实和证据来源。第三节仍为 5 块：`L1-L9`、`L11-L71`、`L72-L199`、`L200-L255`、`L256-L301`；第四节仍为 2 块：`L1-L54`、`L55-L151`。

模型统一使用 `deepseek-v4-pro`、thinking enabled、reasoning effort medium、max tokens 24000、`--no-resume`。运行产物记录的 Extractor 原始字节哈希为 `0a07c1f8b7efda0f47180da4db00851ab48e41f113635549e600a9ee4b8a4174`，Prompt 文本哈希为 `7c2b99ab03140944d1211289e08160992d0ebe2b481fbc9a80639203a2891007`。从当前 Prompt 中仅移除 `chunk.teaching_blocks` 导航段后，文本哈希精确恢复为对照版本的 `4c299d71f6baaed80a04ef6cb40a8db9a634ade22aec2893343a7908e75d30c7`，确认 Prompt 侧只有该单变量。实验结束后只机械统一了工作树的 CRLF 行尾；代码和 Prompt 文本语义未变，但 Extractor 的当前原始字节哈希会因此不同。

角色版的第三节关系稳定性提高。15 条稳定边主要是定义依赖、Claim `involves` 以及两条教材显式推导关系。不过 r3 仍把正、负无穷方向极限指向双向无穷极限表示为 `special_case_of`；教材语义更支持 `defined_in_terms_of`，因此稳定性提高不等于关系已经全部正确。

## Provenance 与结构

六个实验产物均无非法端点、自环、重复边、非法类型或空 LaTeX。第四节 r1 有 1 个宽证据警告，其余无结构警告。

确定改善发生在 provenance。第四节对照 r1 曾把 L110-L112 的铅直渐近线证据整体标为 `example`；v1.5.5 明确把 L112 的一般性陈述标为 `paragraph`，六个角色版产物均没有节点、关系或表达式使用 `example` 角色证据。该变化提高了来源解释的可信度，但没有稳定提升语义召回。

## 结论

1. 单独向模型暴露 block role 不是有效的节点质量优化：第三、四节平均 F1 均低于对照，且差异主要来自稳定漏抽和 Claim kind 错分；
2. 角色信息对 provenance 有确定价值，对第三节关系稳定性有正向信号，但第四节没有复现该收益；
3. 当前问题不是模型不知道某段叫 `example` 或 `theorem`，而是一个 chunk 内仍混合了多个教学功能，模型的注意力预算和建点选择没有随角色自动重分配；
4. `teaching_blocks` 应保留为诊断与后续分块基础，但不能据此宣称语义抽取已改善；
5. 下一轮最有价值的受控实验，是实际改变分块边界：在不使用重叠滑窗的前提下，隔离长例题，并让“定义/一般化陈述/定理”成为独立核心块。第三节优先在 L150 前切开例题与单侧极限定义，第四节优先拆分 `L55-L79`、`L81-L111`、`L112-L114`、`L116-L151`；
6. 新策略仍应跑三轮，并同时观察节点 F1、Claim kind、关系 Jaccard、表达式覆盖和成本，不能只比较单轮最好结果。
