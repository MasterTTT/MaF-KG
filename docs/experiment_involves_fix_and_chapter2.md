# 实验记录：involves 收敛 + 例题局部节点修复 + 第二章泛化

日期：2026-08-15（session 内）
分支：`codex/layer1-coverage-baseline`
Schema：`maf-kg.semantic.v1.7.0`；provider `opencode-go`，model `deepseek-v4-flash`，reasoning_effort=high。

## 0. 目标

在第一章整章图（197 节点 / 301 关系）完成后，对 layer-1 暴露出的三处系统性问题做根因分析与修复，局部验证后把同一 pipeline 泛化到第二章全部，最后做完整评估。

## 1. 发现的问题与根因

### 1.1 例题局部节点泄漏

现象：放开例题抽取（example_sequence 不再硬跳过）后，例题解答里的局部内容被抽成了独立节点：

- `a/x^n 在 x→∞ 时的极限`（第五节例5解答里的一步计算，孤立）
- `x = sgn x · |x| 恒等式`（第一节例7的局部恒等式）
- `重要极限 (1+1/x)^x`（第六节例题引入的"名字"Concept，与 identity Claim 重复，孤立）

根因：prompt 例题豁免条款（"example region may still state ... reusable identity about general objects"）里的 "general objects" 被模型读成了**表面信号**——自由参数（对一般 a,n）、全称量词（对任意实数）、命名（"重要极限"），而不是真正的准入测试"教材独立教授/命名/在例题外复用"。

### 1.2 involves 过度泛化锚点

现象：Claim 连了几乎没有区分能力的上位概念 `函数`：

- `函数极限的夹逼准则 → 函数 + 函数的极限`
- `对称区间上函数可分解为偶函数与奇函数之和 → 偶函数 + 函数 + 奇函数`
- `常数因子可提到极限记号外 → 函数`（只有 `函数`，没有 `函数的极限`）

根因：prompt 缺少"已连具体概念就不再连上位概念"的规则。

### 1.3 involves 剪枝过狠（派生 Claim 被剪到 0 锚）

现象（第一章整章图 197 节点 / 301 关系的精确统计）：

- involves 143 条，占 47.5%；99 个 Claim 平均 1.44 条 involves；80 个 Claim 有 1–4 个锚点；**19 个 Claim 没有任何 involves**。
- 19 个无锚 Claim 的构成：**13 个是被剪枝规则删光的**（`介值定理`、`常数与无穷小的乘积是无穷小`、`双曲余弦的二倍角公式`、`双曲正弦的二倍角公式`、`双曲函数恒等式 ch²x−sh²x=1`、`函数极限的幂运算法则`、`函数极限的保序性`、`有限个无穷小之和/积`、`有限个函数情形的极限运算法则`、`复合映射的顺序性`、`函数极限值的符号性质`、`函数极限的局部保号性（加强形式）`），**6 个是模型一开始就没加锚**（`a/x^n`、`两个子数列收敛于不同极限则数列发散`、`复合函数极限运算法则的无穷极限变体`、`有限个函数情形的极限运算法则`、`极限号与函数符号交换公式`、`非负（非正）项收敛数列的极限符号性质`）。

根因：`_prune_dominated_involves` 按"派生态的锚点与父结论锚点求交集"删除重复锚，但当派生态自己的核心概念恰好也是父结论的核心概念（如 `常数×无穷小` 与 `有界×无穷小` 都锚 `无穷小`）时，交集把派生态的锚全删了，导致 0 锚。

## 2. 修复

### 2.1 prompt `extraction_system.txt`（全局，无局部特化）

1. 例题豁免条款收紧（第 226-235 行）：明确"自由参数 / 全称量词不构成可复用结果；仅当教材将其作为独立命名结果（定理/推论/命名恒等式/命名极限/命名族）或在例题外复用时才抽取"。
2. involves 准入（第 298-308 行）：
   - Claim 只连理解其陈述不可或缺的 1-3 个核心概念；
   - 已连具体概念时不再连过度泛化的上位概念（有 `函数的极限` 就不加 `函数`）；
   - 派生 Claim 仍要连自己的核心概念，`derived_from` 不取代自身锚点，不复制父结论全部 involves，但至少保留一个核心锚。

### 2.2 代码 `agents/Extractor.py` `_prune_dominated_involves`

在剪枝前加"保底一个锚"：若 `duplicate_concepts == 该派生 Claim 的全部锚点`，则保留一个（`set(sorted(duplicate_concepts)[1:])`），绝不把一个派生 Claim 剪到 0 锚。

### 2.3 gold `evaluation/gold/semantic_fourth_section_v1.json`

`无穷大与无穷小的倒数关系` claim_kind `result → property`（原文"定理2"但按语义是结构关系，判 property；gold 与 prompt 口径对齐）。

### 5.2 involves 收敛效果（新 prompt 的关键指标）

- 全图 involves 261（52.5%），180 个 Claim 中 20 个无 involves。
- 这 20 个里 19 个是 seed（第一章旧 prompt）遗留、只有 1 个是第二章新增 → **新增 Claim 无 involves 占比约 1.2%，对比第一章旧图的 19.2%，显著收敛**。

### 5.3 局限与后续

- 第一章旧图（seed）仍带旧 prompt 的问题（例题局部节点、19 个无 involves、过度泛化 `函数`），本次未重抽第一章；若需统一，可后续用新 prompt 重跑第一章增量。
- 4 个新增孤立节点多为"命名但未发展"的引例/应用概念与方法，可后续按孤立节点审计回收。

## 6. 关键结论

1. 例题豁免条款的 "general" 必须锚定在"教材独立命名/复用"，而非表面量词/自由参数。
2. involves 是语义锚定边，不是逻辑边；准入标准应是"1-3 个不可或缺核心概念 + 不连上位概念 + 派生 Claim 保一个核心锚"。
3. 剪枝去重要"保底一个锚"，否则派生结论在检索层完全依赖 derived_from 链。
