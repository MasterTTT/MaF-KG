## 稳定错误

以下四个过细 Concept 在三轮中全部出现：

- 独立 `左极限`；
- 独立 `右极限`；
- 独立 `x→+∞` 时的函数极限；
- 独立 `x→-∞` 时的函数极限。

按 Gold，前两者应合入 `单侧极限`，后两者应合入 `自变量趋于无穷大时的函数极限`。这说明当前 independent-reference test 倾向于保留可单独引用的方向分支，与第一层“中心教学目标”粒度存在稳定冲突。

以下 M 节点三轮均未召回：

- `去心邻域`；
- `ε-δ论证法`；
- `ε-X论证法`。

`函数极限与趋近点处的函数值无关`仅在一轮召回；有限点函数极限、单侧极限和水平渐近线各在两轮召回。一般函数极限、无穷远函数极限、左右极限判据以及性质定理类 Claim 的召回相对稳定。三轮均未从例题提升具体函数或具体极限节点，Claim kind 也未出现错分。

## 关系与表达式稳定性

关系尚无人工 Gold，不能报告 Precision、Recall 或 F1。将每轮关系端点对齐到 Gold 节点后，关系集合 Jaccard 为：

| 轮次对 | Jaccard |
| --- | ---: |
| r1--r2 | 0.8182 |
| r1--r3 | 0.2500 |
| r2--r3 | 0.1935 |

只有 6 条关系三轮稳定，其中 4 条依赖 Gold 判定为过细的方向分支节点。MathExpression 数量在 5、12、9 之间波动。因此，当前关系和表达式层的稳定性明显弱于节点层，不能直接作为第二层依赖推理的可靠输入。

## 评估器修正

r2 首次结构评估暴露出名称规范化 bug：评估器删除了数学负号，错误地把 `x→∞` 与 `x→-∞` 视为同名。现已改为保留正负号及连字符，并增加回归测试。修正后三轮严重结构问题均为 0。

## 结论

第三节盲测没有达到建议的 0.85 节点 F1 泛化门槛。第一层已足以支持人工审核后的 KnowledgeUnit 聚合原型，但还不能作为稳定的全教材自动抽取器冻结。下一轮第一层改进应聚焦两个系统问题：方向对称子概念的合并策略，以及定义性辅助 Concept/Method 的覆盖；不应继续针对单个节点名称堆提示词。
