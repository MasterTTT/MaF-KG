# 前两节 Gold Standard 审核表 01

## 用途

本文件用于冻结第一层语义图的人工评价边界。它不是模型输出，也不是抽取规则；后续评估只用它计算节点与关系的 Precision、Recall 和 F1。

标记含义：

- `M`：必须抽取，缺失计为 false negative；
- `O`：可选，抽取不计为 false positive，缺失也不计为 false negative；
- `X`：禁止作为独立节点，抽取计为 false positive；
- `Merge`：语义内容必须保留，但并入指定的第一层节点。

## 已确认边界

| 内容 | 决策 | 第一层表示 |
| --- | --- | --- |
| ε 邻域、全称量词、存在量词 | O | 可作为 Concept，但不要求必须召回 |
| 单调增加、单调减少 | Merge | 合入 `单调函数`，description 保留两个方向的完整定义 |
| 有界、无界 | Merge | 合入对应对象的 `有界性`，description 同时保留正反定义 |
| 函数和、差、积、商 | Merge | 建立一个 `函数的四则运算` Concept，保留四类运算及定义域条件 |
| 双曲函数渐近行为 | O | 可作为 Property Claim，不要求必须召回 |
| 解释性等价式或改写 | X，除非教材明确作为判据讲授 | 仅承担解释或 MathExpression，不自动成为 Claim |

## 默认认定为 M 的第一节节点

以下节点边界明确，暂不占用人工审核时间。

### Concept

`映射`、`定义域`、`值域`、`像`、`原像`、`单射`、`满射`、`一一映射`、`逆映射`、`复合映射`、`函数`、`函数图形`、`自然定义域`、`函数有界性`、`单调函数`、`奇函数`、`偶函数`、`周期函数`、`反函数`、`复合函数`、`函数的四则运算`、`基本初等函数`、`初等函数`、`幂函数`、`指数函数`、`对数函数`、`三角函数`、`反三角函数`、`双曲函数`、`双曲正弦`、`双曲余弦`、`双曲正切`、`反双曲正弦`、`反双曲余弦`、`反双曲正切`。

规范合并：

- `双射`、`一一对应`作为`一一映射`的 aliases；
- `单调增加`、`单调减少`不得形成独立第一层节点；
- `有界函数`、`无界函数`不得形成两个独立第一层节点；
- `函数和`、`函数差`、`函数积`、`函数商`不得形成四个独立第一层节点。

### Claim

- 函数相等判定准则：`criterion`
- 逆映射存在条件：`criterion`
- 复合映射构成条件：`criterion`
- 复合映射非交换性：`property`
- 符号函数与绝对值恒等式：`identity`
- 函数有界的充要条件：`criterion`
- 奇函数图形关于原点对称：`property`
- 偶函数图形关于 y 轴对称：`property`
- 函数奇偶分解结论：`property`
- 并非每个周期函数都有最小正周期：`property`
- 单调函数的反函数存在且保持单调：`property`
- 直接函数与反函数图形关于 y=x 对称：`property`
- 双曲正弦、双曲余弦和双曲正切的奇偶性与单调性：按独立完整命题分别建 `property`
- 双曲正切有界、双曲余弦具有最小值：按独立完整命题建 `property`
- 教材明确列出的七个双曲函数恒等式（公式 1-3 至 1-9）：分别建 `identity`
- 反双曲函数正文明确陈述的奇偶性与单调性：按独立完整命题分别建 `property`

## 默认认定为 M 的第二节节点

### Concept 与 Method

- `数列`：Concept
- `数列的极限`：Concept；description 包含收敛与发散的定义边界
- `数列有界性`：Concept；description 同时包含有界与无界
- `子数列`：Concept
- `ε-N 论证法`：Method

### Claim

- 收敛数列极限唯一：`property`
- 收敛数列必有界：`property`
- 数列有界是收敛的必要非充分条件：`criterion`
- 收敛数列保号性：`property`
- 项最终非负或非正时极限保号的推论：`property`
- 收敛数列的任一子数列收敛于同一极限：`property`
- 两个子数列收敛到不同极限则原数列发散：`criterion`

## 默认认定为 X 的节点

- 例题中的具体数列、具体函数、局部变量、局部中间结论与证明步骤；
- “两个数的接近程度可用差的绝对值度量”作为 Claim；
- `|x_n-a|<ε` 与 `a-ε<x_n<a+ε` 的解释性等价作为 Claim；
- 例题中 `|q|<1` 时具体等比数列极限为 0 的结论作为第一层 Claim；
- 定理编号、例题编号、图号、章节名和教学话语作为节点；
- 仅为连接孤立节点而创建的关系或节点。
