# 第一层语义图迭代记录 03

## 目标与变量

本轮从 `maf-kg.semantic.v1.3` 升级至 `maf-kg.semantic.v1.4`，只调整节点选择与 Claim 分类提示词，不改变分块、顺序 Top-K memory、关系 schema 或全局图合并机制。

主要假设：

1. Claim 不能只满足“可判真”，还必须是教材独立讲授的可复用结论；
2. Criterion 必须承担判断功能，普通等价改写和解释性观察不构成 Criterion；
3. Concept 不必是 chunk 的唯一中心主题，教材明确引入的可复用辅助概念也应覆盖；
4. `property / criterion / identity / result` 应按数学语义而非教材标签分类。

两节均使用 `deepseek-v4-pro`、thinking enabled、reasoning effort medium、max tokens 24000，并关闭本地断点读取。实验 JSON 与缓存只保存在本地。

## 第二节定向实验

| 指标 | v1.3 | v1.4 |
| --- | ---: | ---: |
| 节点 | 16 | 14 |
| Claim / Concept / Method | 9 / 6 / 1 | 7 / 6 / 1 |
| 关系 | 22 | 21 |
| MathExpression | 4 | 5 |
| Criterion | 4 | 1 |
| Property | 0 | 5 |
| `derived_from` | 1 | 2 |
| 孤立节点 | 2 | 2 |

Claim 入场门槛有效：“接近程度可用差的绝对值度量”和“绝对值不等式等价性”两个解释性伪 Claim 消失。极限唯一性、收敛数列有界性和保号性被归入 Property；由保号性推出的推论以及由子数列定理推出的发散准则均保留了 `derived_from`。

Concept 覆盖只部分改善：全称量词和存在量词被恢复，但 `ε 邻域` 仍漏掉。v1.4 将收敛/发散合并进“数列的极限”定义，将有界/无界合并进“有界数列”定义，粒度更符合第一层教学单元，但这仍是建模选择，不能仅以节点减少判定为优点。

## 第一节回归实验

| 指标 | v1.3 | v1.4 |
| --- | ---: | ---: |
| 节点 | 82 | 78 |
| Claim / Concept | 32 / 50 | 35 / 43 |
| 关系 | 129 | 114 |
| MathExpression | 47 | 36 |
| Criterion / Identity / Property / Result | 4 / 8 / 18 / 2 | 4 / 8 / 23 / 0 |
| 孤立节点 | 0 | 0 |
| 宽证据节点 | 2 | 4 |

v1.4 保留了复合映射非交换性、逆映射存在条件、函数相等准则、函数有界准则及八个公式恒等式，并新增了正文明确介绍的“ 双曲函数”总类 Concept。双曲函数的单调性、奇偶性、有界性和渐近行为被稳定表示为 Property。

粒度方面，单调增加与单调减少被合并进“单调函数”，有界与无界被合并进“有界函数”，双射规范为“一一映射”并保留别名。这些合并与第一层以教材中心教学单元为边界的目标一致。函数和、差、积、商四个细节点被去除，但没有生成“函数的运算”总节点，形成新的覆盖缺口。

主要退化：

1. 定义表达式由 37 降至 26，单调函数和函数运算的关键表达式未附着；
2. 反双曲正弦、反双曲余弦的证据跨度扩大，宽证据节点由 2 增至 4；
3. 第二节仍漏掉 `ε 邻域`；
4. 第一节后半段单个 chunk 的 Top-K memory prompt 仍接近 5 万 tokens；
5. 一次请求总耗时超过 400 秒，Pro 模型的延迟波动较大。

## 评估工具修正

旧 `scripts/evaluate_kg.py` 只读取 `relationships`、`source` 和 `target`，因此会把 semantic schema 的 `relations`、`source_id` 和 `target_id` 错误报告为 0 条关系和全部孤立节点。

本轮新增 semantic-schema 专用评估路径，检查：

- 节点类型与 Claim 分类；
- 关系类型、方向签名、端点、自环和重复边；
- MathExpression owner、role 与 LaTeX；
- 节点、关系和表达式证据结构；
- 同类型规范名重复、孤立节点、连通分量和宽证据。

评估器不判断数学语义，也不修改或回填抽取结果。当前 17 项单元测试全部通过，两份 v1.4 图均无严重结构问题。

## 人工 Gold 节点评估

A1--A8 已全部按审核表建议冻结，机器可读标注现已扩展为 `evaluation/gold/semantic_first_three_sections_v1.json`。`Merge` 不作为独立计分标签，而是展开为“总节点 M、被拆出的细节点 X”。预测节点按类型、Claim kind 和人工接受名称匹配；可选节点不计 FP 或 FN，Claim kind 错分同时产生 FP 与 FN。

| 图谱 | TP | FP | FN | Optional 命中 | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 第一章第一节 | 66 | 0 | 1 | 12 | 1.0000 | 0.9851 | 0.9925 |
| 第一章第二节 | 11 | 1 | 1 | 2 | 0.9167 | 0.9167 | 0.9167 |

第一节唯一 FN 是 `函数的四则运算`。第二节唯一语义错分是将“数列有界是收敛的必要非充分条件”标为 `result`；Gold 将其视为可用于判断收敛必要条件的 `criterion`，因此产生一项 FP 和一项 FN。

结构上，第一节有一个由绝对值函数、符号函数及其恒等式构成的 3 节点独立分量；第二节的全称量词、存在量词为两个孤立可选节点。第一节另有 4 个节点的证据跨度超过 20 行。关系尚未逐条人工标注，因此关系 Precision、Recall 与 F1 均保持 `pending`，不能由节点分数推断。

## 结论

v1.4 明确提升了 Claim 精度和第一层节点粒度。人工 Gold 显示第一节节点层已接近冻结边界，第二节仍存在 Claim kind 错分；Concept 与 MathExpression 召回也仍不稳定。由于 DeepSeek thinking 模式存在随机性，而 v1.3、v1.4 各只有一次完整运行，本轮差异不能全部归因于提示词修改。

下一步不宜继续针对单个漏点堆提示词。应先人工标注少量关键关系，再进行至少两次独立重复运行，报告节点与关系的 precision、recall、F1、重复率和关系端点完整率。之后再判断是否需要引入更细的教学单元分块或表达式覆盖复核。
