# Top-K Memory Extraction Experiment (v7)

## 1. Experiment Objective

This experiment evaluates whether a sequential extractor with bounded global-graph memory can reduce cross-chunk duplicate nodes while preserving textbook-grounded nodes and relations. The extractor processes one chunk at a time, retrieves a relevant subset of the graph built so far, and asks the model to either create a node or reuse a supplied node.

The experiment is limited to extraction quality. Neo4j import, learner modeling, prerequisite inference, and learning-path recommendation are outside its scope.

## 2. Configuration

- Source: `data/raw/第一章第二节.md`
- Model: `deepseek-v4-pro`
- Reasoning effort: `medium`
- Thinking mode: `disabled`
- Chunking: structure-aware, 5 chunks over 372 source lines
- Node memory limit: 40
- Relation memory limit: 60
- Resume cache: enabled by the implementation, with 0 cache hits in the reported run
- Output schema: `maf-kg.agent.v7`

The reported output was generated with:

```powershell
.venv\Scripts\python.exe -u -X utf8 agents\Extractor.py `
  --input "E:\MaF-KG\data\raw\第一章第二节.md" `
  --output "KG\第一章第二节_kg_v7_topk_contract_v4_pro_medium.json" `
  --provider deepseek `
  --model deepseek-v4-pro `
  --reasoning-effort medium `
  --thinking disabled `
  --no-proxy `
  --max-retries 4 `
  --request-delay 8
```

## 3. Method

For each chunk, the program retrieves a compact memory view from the current global graph. Retrieval combines exact name matches, alias matches, character n-gram overlap, exact LaTeX matches, recency over the previous two chunks, and one-hop neighbor expansion. The model receives only this selected memory rather than the full accumulated graph.

Each node action is explicit:

- `create`: add a new mathematical entity grounded in the current chunk;
- `reuse`: attach the current mention and evidence to a supplied existing node;
- invalid actions or relations: reject the individual item and record a diagnostic without terminating the run.

Unlinked `Concept`, `Property`, and `Theorem` nodes are retained as `pending_unlinked`, because later chunks may connect them. Unlinked `Formula`, `Example`, `Proof`, and `Figure` nodes are removed. Formula LaTeX is resolved from an exact source candidate instead of being regenerated by the model.

Across the five chunks, the model made 24 create decisions and 13 reuse decisions. Reuse therefore accounts for 35.1% of accepted node decisions. Four relations with invalid type signatures were rejected and retained in diagnostics rather than causing a complete extraction failure.

## 5. Quality Assessment

The memory mechanism successfully reused recurring entities such as `数列`, `数列的极限`, `收敛`, and `发散`. It also reused the earlier `例4` node when the textbook cited that example again. The formal epsilon-N definition in a later chunk enriched the existing `数列的极限` node instead of creating another concept.

The node-type boundaries also improved in this run. Theorem names omit source numbering, formal proofs are represented separately, proof-local and example-local expressions are not emitted as Formula nodes, and the earlier noisy `割圆术` node is absent. Exact source LaTeX resolution works for multiline display blocks, including the epsilon-N expression.

However, the Formula precision is not yet satisfactory. `数列的函数表示` (`x_n=f(n)`) was still emitted as a Formula even though the source does not explicitly name it as a reusable formula. This is the principal false positive in the final graph and indicates that prompt-only Formula constraints remain imperfect.

## 6. Validity and Limitations

This is a single-section case study, not a general benchmark. The observed reuse rate demonstrates that the memory path was exercised, but it does not by itself prove semantic deduplication accuracy. There is no manually annotated gold graph yet, so precision, recall, and F1 cannot be reported rigorously.

The memory retriever is lexical and recency-based. It can miss semantically equivalent nodes with little surface-form overlap when they fall outside the Top-K window. Conversely, the model can still reuse a related but non-identical node. The current graph also captures mostly explicit textbook relations; deeper logical dependency and multi-premise inference are intentionally deferred to a later graph layer.

## 7. Conclusion and Next Experiment

The v7 experiment supports retaining a bounded Top-K memory mechanism: it reduces repeated entities across chunks without restoring the earlier multi-agent normalization pipeline, and invalid local outputs no longer abort the whole document. The current version is suitable as an experimental baseline, but not yet as a validated production extractor.

The next rigorous step is to annotate a small gold set spanning multiple sections, then measure node deduplication precision, node and relation extraction precision/recall, Formula false-positive rate, and sensitivity to memory size. Formula eligibility should be tested as an explicit extraction decision rather than inferred from the presence of a mathematical expression.
