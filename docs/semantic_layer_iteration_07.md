## 实验目标

1. v1.5.7 检验“中等粒度人工分块 + 跳过纯例题块”能否稳定改善第三、四节抽取；

## v1.5.7 第三节结果

三次独立尝试中两次成功，一次在 `L150-L170` 因四个 create action 均漏必填 `mention` 而严格失败。

成功样本平均 F1 为 `.8992`，与 v1.5.5 roles 三轮均值 `.8907` 接近，不能在存在 `1/3` 失败率的情况下认定节点质量提升。

确定的正向结果：

- 两个成功样本均恢复 2 条教材显式 `derived_from`；
- 所有纯例题块均被审计跳过，没有例题局部节点进入图；
- 两个结果均为单一连通分量，无孤立点、非法签名、宽证据或 LaTeX 来源问题。

仍存在的问题：

- r1 把“函数极限与数列极限的关系”错分为 property；
- r1 将局部绝对值下界命名成含混的“极限非零时的局部保号性”；
- `去心邻域`两轮均漏，`单侧极限`仅 r1 命中；
- 成功样本关系 Jaccard 为 `.5385`，低于 v1.5.5 roles 的 `.9048/.7273/.6522`；
- MathExpression 数量为 `10/6`，LaTeX 均逐字来自原文，但集合 Jaccard 仅 `.6000`。

两个成功样本平均记录 token 为约 `130831`，平均 API latency 为约 `550.4s`。失败轮已消耗的请求 telemetry 未落盘，因此真实成本更高。

## v1.5.7 分块结论

1. 跳过经过严格 block 审计的纯例题块是确定的工程收益，应保留；
2. “中心性质 + 紧邻加强形式/推论”能够恢复第三节的显式 `derived_from`，比逐定理原子切分合理；
3. 中粒度人工分块没有稳定改善节点 F1、关系集合或表达式覆盖，暂不具备模板化证据；
4. 手工行号 span 只适合作为消融实验，不具备跨章节泛化能力；
5. 分块有效但不是充分条件，输出 schema 遵从和模型内容选择是独立瓶颈。

## v1.5.8 工程修复

六次 v1.5.7 尝试中有两次因 create action 缺 `mention` 失败。代码审查确认，create 的 `mention` 只进入审计 ledger，不参与节点构建、证据恢复、ID 或关系解析；create 已有 canonical name 与 evidence。相反，reuse 的 `mention` 用于审核模型是否复用了同一表面/语义节点。

因此 v1.5.8 直接修改契约：

- create action 的 `mention` 为可选，Prompt 示例不再要求输出；
- reuse action 的非空原文 `mention` 仍严格必填；
- 不自动补字段，不重试 schema 错误，不做 fallback 抽取；
- schema 失败时保存原始 JSON、错误、完整 API usage、已处理 chunk、partial counts 和 chunk summaries；
- stdout/stderr 在 CLI 内显式切换 UTF-8，修复成功落盘后因 GBK 打印失败的问题；
- schema、默认输出和 cache namespace 升级到 v1.5.8。

新增测试覆盖 create 省略 mention、reuse 缺 mention 失败，以及 schema 失败 telemetry 落盘。完整测试为 `32/32` 通过。

## v1.5.8 第四节验证

为了验证契约而非重新评价 chunk，使用同一第四节 span 连续运行三轮：

| Run | Nodes | Relations | Expressions | TP/FP/FN | F1 | Tokens | API latency |
| --- | ---: | ---: | ---: | --- | ---: | ---: | ---: |
| r1 | 8 | 7 | 5 | 8/0/1 | .9412 | 64214 | 290.4s |
| r2 | 5 | 4 | 2 | 4/1/5 | .5714 | 55287 | 258.0s |
| r3 | 10 | 10 | 5 | 9/0/0 | 1.0000 | 74161 | 463.4s |

三轮 schema 与 CLI 均成功。模型共返回 23 个省略 mention 的 create action，全部按新契约接受；所有 reuse action 均提供非空 mention。该结果验证了工程修复，但语义 F1 的均值 `.8375`、总体标准差 `.1897`，仍显示很大的采样波动。

必抽节点命中频率：

- `3/3`：无穷小、无穷大、函数极限的无穷小表征、无穷大与无穷小的倒数关系；
- `2/3`：正无穷大、负无穷大、铅直渐近线、无穷大函数不存在有限极限；
- `1/3`：零是唯一的常数无穷小。

r2 将铅直渐近线误建成 property Claim“无穷大极限与铅直渐近线的关系”。三轮关系 Jaccard 为 `.3750/.7000/.2727`，只有 3 条边三轮稳定；MathExpression 原始数量为 `5/2/5`，集合 Jaccard 为 `.5000/.6000/.2000`。因此节点高分没有同步证明关系层稳定，关系 Gold 仍为 `pending`，不能报告关系 Precision/Recall/F1。

Gold 仅追加了人工核验的等价表面名称，没有改变任何 M/O/X、node type 或 Claim kind。倒数关系若错分 property，仍同时计 FP 与 FN；“无穷大不是数”仍为明确禁抽项。

## 最终判断

本轮最可信的成果不是“新分块已经泛化”，而是：

1. 纯例题块可以在严格覆盖审计后安全跳过；
2. 相关定理与紧邻推论应保留在同一局部语义块；
3. create/reuse 输出契约现已符合字段实际用途，失败审计和 Windows CLI 也更可靠；
4. 手工中粒度 span 对语义质量的收益没有稳定复现，不能直接推广为通用模板；
5. 下一轮不应继续手调行号，而应实验可观测的教材教学单元构造：由解析器生成“中心定义/定理/性质 + 紧邻解释或推论”的候选单元，同时单独标记并跳过纯例题，再保持同一 Extractor 做三轮盲测。
